- [ ] **エクスプロイト**トランザクションをレビューして脆弱性を特定する - **[*担当者*]**
    - 使用ツール:

        - [Foundryトランザクションリプレイトレース/デバッガー](https://book.getfoundry.sh/reference/cast/cast-run.html#cast-run)

- [ ] **コントラクトを一時停止**（可能な場合）、他の防御アクションを取る、攻撃的アクション（ホワイトハットレスキューなど）を検討する - **[*調整担当者*]**
  - ステップ:
    - **[*誰が、どのように、どのアドレスで*]**
  - トランザクションのレビュー - **[\*担当者、**トランザクションを作成した人とは異なるべき**\*]**
  - 防御アクションを取るために誰が署名できるかを慌てて把握したくはありません。[OpenZeppelin Defender](https://www.openzeppelin.com/defender)の使用が強く推奨されます。また、[ローンチ前セキュリティチェックリスト](https://github.com/nascentxyz/simple-security-toolkit/blob/main/pre-launch-security-checklist.md)に従って、事前に準備された防御アクションスクリプトを用意しておくことも推奨されます。
- [ ] **すべてのコントラクト**をレビューして連鎖的な脆弱性を特定する。必要に応じてそれらを一時停止する - **[*担当者*]**
- [ ] **UI**を更新して現在のステータスを反映する - **[*担当者*]**
- [ ] **セキュリティパートナーに連絡する** - **[*担当者*]**
  - **[*過去の監査人のリストと彼らの連絡先情報または共有チャンネルの場所*]**
    - あなたの監査人は、主に自分の評判を守るためであっても、可能な限り支援したいと思うでしょう
  - 信頼の輪の外の誰も緊急対応室に入れないでください
  - 攻撃者が資金の持ち出しに成功した場合でも、盗まれた資金が回収不能だと思わないでください。すぐに信頼できる関係者（既知のセキュリティ専門家やベンチャー投資家など）に連絡して、関連する法執行機関の連絡先、資産追跡の専門家、回収サービスの紹介を受けてください。
- [ ] 関連するソーシャルメディアコミュニケーションチャンネルを通じて**ユーザーに通知する**。Discord: **[*担当者*]**、Twitter: **[*担当者*]**
  - 意味のある新しい情報や進展が得られたら定期的に更新する
    - 新しいことが何もわからなくても、少なくとも24時間ごとの更新は、あなたがその状況に対処するために取り組んでいることをコミュニティに安心させるのに役立ちます
    - すべてのメッセージを脆弱性レビュアーに確認してもらい、セキュリティを危険にさらしたり、すべての事実が判明する前に特定の修復を約束したりする情報が誤って共有されないようにしてください
